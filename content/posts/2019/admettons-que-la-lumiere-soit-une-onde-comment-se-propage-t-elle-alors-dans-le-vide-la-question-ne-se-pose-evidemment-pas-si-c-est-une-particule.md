Vous pouvez créer un champ électrique dans le vide. Par exemple dans un tube cathodique, la différence de potentiel accélère des électrons. Vous pouvez aussi créer un champ magnétique dans le vide. Par exemple dans le même tube cathodique, des bobines permettent de dévier l'électron.

La lumière étant une [Onde électromagnétique](w:) elle se propage dans le vide en faisant osciller le [Champ électromagnétique](w:).
