*Réponse publiée [sur Quora](https://fr.quora.com/C-est-quoi-le-produit-de-0-divis%C3%A9-par-0/answer/Dr-Goulu)*

Le résultat d'une division sappelle un quotient :

$dividende / diviseur = quotient$

Le quotient est donc le en nombre qui, multiplié par le diviseur, donne le dividende :

$quotient \times diviseur = dividende$

Vous voyez donc que si le diviseur vaut 0, le dividende doit obligatoirement être 0 et que le quotient peut être n'importe quoi.

Le quotient est indéterminé. C'est le terme officiel.
