*Réponse publiée [sur Quora](https://fr.quora.com/Comment-montrer-que-la-m%C3%A9decine-est-une-discipline-scientifique/answer/Dr-Goulu)*

La médecine n'est pas une discipline scientifique. C'est au moins 44 disciplines scientifiques (allergologie ; anatomie et cytologie pathologique ; anesthésie ; cardiologie ; dermatologie ; endocrinologie-nutrition ; génétique ; gériatrie ; gynécologie médicale ; hématologie ; hépato-gastro-entérologie ; maladies infectieuses et tropicales ; médecine du travail ; médecine générale ; médecine interne ; médecine nucléaire ; médecine physique et réadaptation ; néphrologie ; neurologie ; oncologie ; pédiatrie ; pneumologie ; psychiatrie ; radiologie ; réanimation ; rhumatologie ; santé publique ; urgentiste ; chirurgie esthétique ; chirurgie maxillo-facial-stomatologie ; chirurgie pédiatrique ; chirurgie vasculaire ; chirurgie viscérale et digestive ; gynécologie obstétrique ; médecine légale ; neurochirurgie ; ophtalmologie ; ORL (oto-rhino-laryngologie) et chirurgie cervico-faciale ; orthopédie ; urologie)

qui suivent toutes la méthode scientifique, concrétisée par des milliers de publications revues par les pairs dans des journaux spécialisés.

Pour vous en convaincre, il suffit de les lire.
