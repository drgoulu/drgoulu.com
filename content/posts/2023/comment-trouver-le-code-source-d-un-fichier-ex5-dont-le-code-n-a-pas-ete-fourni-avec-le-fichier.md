*Réponse publiée [sur Quora](https://fr.quora.com/Comment-trouver-le-code-source-d-un-fichier-ex5-dont-le-code-n-a-pas-%C3%A9t%C3%A9-fourni-avec-le-fichier/answer/Dr-Goulu)*

Vous voulez probablement dire .exe, pas .ex5.

Vous ne pouvez pas retrouver le code source original, mais vous pouvez peut-être utiliser un [Décompilateur](w:)pour retrouver un code qui peut être recompilé pour obtenir le même exécutable.

Mais ce code sera probablement très difficile à comprendre, donc à modifier car il ne contient pas des identificateurs (noms de variables ou de fonctions) explicites, et encore moins des commentaires.
