On ne "pose" pas des nombres comme ça. La suite des entiers est définie par l'addition successive de 1 : 2=1+1, 3=2+1=1+1+1

Avec "votre" base 2, ca ne marche pas. Ce n'est pas un problème d'addition, c'est un problème dans la suite des entiers successifs.
