Pas tellement au niveau du langage, vous allez retrouver en python l'équivalent de tout ce qui existe en php, mais le framework [Django](w:Django_(framework)) repose sur des notions avancées… le tuto Django est simple, mais après la courbe d'apprentissage est assez raide…
