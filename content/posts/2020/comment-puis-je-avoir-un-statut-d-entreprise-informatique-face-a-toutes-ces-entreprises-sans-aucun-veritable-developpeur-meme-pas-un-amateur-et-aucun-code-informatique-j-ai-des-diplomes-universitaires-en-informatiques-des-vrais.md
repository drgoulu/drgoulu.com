Pour avoir un statut d'entreprise, vous créez une SA, Sàrl ou autre (voir [Sociétés - Guichet-entreprises.fr](https://www.guichet-entreprises.fr/fr/creation-dentreprise/les-prealables-a-la-creation-dentreprise/les-formes-juridiques/societes/))

Pour être une entreprise informatique, les clients sont plus importants que le code ou les diplômes. Les clients ne paient ni les diplômes ni le code. Ils paient les "vraies solutions" avec un e.

Ce qui est le plus difficile, c'est de convaincre le premier client que votre solution est la bonne. Ça prendra 10x plus de temps que de la développer.

C'est comme ça que "toutes ces entreprises sans aucun véritable développeur, même pas un amateur, et aucun code informatique" marchent : elles ont des vendeurs.
