[Erreur HTTP 404 — Wikipédia](w:Erreur_HTTP_404)

> l’erreur **404** est un [code](w:Liste_des_codes_HTTP) du [protocole de communication](w:) [HTTP](w:Hypertext_Transfer_Protocol) sur le [réseau Internet](w:) pour signaler un incident. Ce code est renvoyé par un [serveur HTTP](w:) pour indiquer qu'aucune ressource, généralement une [page web](w:), n'a été trouvée à l'[adresse](w:Adresse_URL) demandée
