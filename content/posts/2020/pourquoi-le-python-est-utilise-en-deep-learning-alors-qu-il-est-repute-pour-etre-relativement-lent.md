- Sa réputation est donnée par les gens qui ne savent pas utiliser des librairies compilées
- Les librairies de deep learning sont compilées.

Python est un génial langage de script qui permet de coder rapidement les 90% du code qui tournent 10% du temps, et de linker les 10% de code C/C++ qui tournent 90% du temps.
