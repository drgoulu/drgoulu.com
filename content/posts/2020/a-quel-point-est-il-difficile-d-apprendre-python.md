*Réponse publiée [sur Quora](https://fr.quora.com/A-quel-point-est-il-difficile-d-apprendre-Python/answer/Dr-Goulu)*

Si vous connaissez déjà un langage de programmation, Python vous semblera plus facile, plus clair, plus concis.

Si vous n'en connaissez pas, apprendre la programmation avec Python est une bonne idée si vous vous intéressez aux algorithmes et aux programmes qui font beaucoup de choses avec peu de données, mais si vous voulez faire quelque chose de joli et d'interactif, je vous conseillerais plutôt HTML5+JavaScript (ou TypeScript).
