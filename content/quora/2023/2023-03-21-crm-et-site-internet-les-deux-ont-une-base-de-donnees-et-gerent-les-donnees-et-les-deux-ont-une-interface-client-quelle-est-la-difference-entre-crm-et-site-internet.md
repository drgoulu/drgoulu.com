Je pense que vous confondez CRM (customer management system) et CMS (content management system, [Système de gestion de contenu](w:))

Un CRM (le plus connu est salesforce) est destiné à faire du suivi client. Sa base de données a des tables pour les clients, les personnes de contact, les commandes etc.

Un CMS (le plus connu est WordPress) "propulse" un site Web dynamique. Sa base de données à des tables pour les articles, les commentaires, etc.

Même si les technologies de l interface utilisateur sont les mêmes( html 5, javascript, base de données), ce sont des applications aussi differentes qu'un tableur (CRM) ou un traitement de textes (CMS)
