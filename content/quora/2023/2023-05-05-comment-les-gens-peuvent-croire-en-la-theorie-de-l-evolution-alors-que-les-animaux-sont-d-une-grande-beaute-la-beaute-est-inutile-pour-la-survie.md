L a beauté est indispensable pour la survie d une espèce, sinon les couples ne se formeraient pas, ils n'auraient pas de petits et disparaîtraient.

Pour tous les animaux ci-dessus comme pour vous, les femelles de votre espèce sont belles pour les mâles et les mâles sont beaux pour les femelles.

Il ne faut pas "croire" à l'évolution. Il suffit d'ouvrir les yeux pour constater qu'elle correspond à ce qu'on voit, et étudier un peu pour savoir comment elle fonctionne.
