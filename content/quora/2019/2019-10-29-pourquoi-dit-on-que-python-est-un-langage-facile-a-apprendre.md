*Réponse publiée [sur Quora](https://fr.quora.com/Pourquoi-dit-on-que-Python-est-un-langage-facile-%C3%A0-apprendre/answer/Dr-Goulu)*

Parce qu'il l'est.

Si vous ne connaissez aucun langage de programmation, Python vous permettra d'apprendre la programmation en acquérant de bons réflexes : indentation, variables locales, …

Si vous connaissez d'autres langages de programmation, Python vous apparaîtra plus simple pour tout.

Avec un peu de pratique vous verrez qu'il n'y a rien de superflu ou de verbeux en Python. Tout est aussi simple et clair qu'il doit l'être.
