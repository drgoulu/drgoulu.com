*Réponse publiée [sur Quora](https://fr.quora.com/Pourquoi-dit-on-que-Python-est-un-langage-facile-à-apprendre/answer/Dr-Goulu)*

Tu n'indente pas ton code (C ou Java,…) pour le rendre lisible ? Si ? Alors à quoi servent les accolades ? ;-)

Accessoirement, l'indentation significative encourage vivement à écrire de petites fonctions qui ne dépassent pas un écran. Le fait que les variables sont locales au bloc permet de refactorer la 3ème boucle imbriquée en une fonction très facilement
