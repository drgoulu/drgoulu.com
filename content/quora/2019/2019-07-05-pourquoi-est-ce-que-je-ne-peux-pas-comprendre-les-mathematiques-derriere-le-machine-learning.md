Les mathématiques derrière l'[Apprentissage automatique](w:) ne sont pas simples. Ce sont des recherches universitaires récentes qui ont permis à ces techniques d'émerger. Il faut de bonnes bases en algèbre linéaire, statistiques, systèmes dynamiques pour aborder ce domaine. Si vous les avez, vous pouvez les rafraîchir avec un MOOC comme [Mathematics for Machine Learning | Coursera](https://www.coursera.org/specializations/mathematics-machine-learning) par exemple. Si vous ne les avez pas, ce sera dur…

Cela dit, il n'y a pas forcément besoin de savoir comment fonctionne un moteur pour conduire une voiture. Si vous ne voulez pas développer vos propres algos mais utiliser ceux existant, il vous faut principalement connaitre les avantages et inconvénients de chacun
