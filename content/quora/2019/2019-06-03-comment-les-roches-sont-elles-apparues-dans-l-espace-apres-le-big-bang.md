*Article initialement publié sur [Quora](https://fr.quora.com/Comment-les-roches-sont-elles-apparues-dans-l-espace-apr%C3%A8s-le-Big-Bang/answer/Dr-Goulu)*

Les éléments qui les composent (silicium, fer, aluminium, oxygène etc.) ont été produits par fusion dans les premières étoiles et éjectés dans l'espace par leurs supernovas.

Les nuages moleculaires de ces matériaux se sont agrégés autour de nouvelles étoiles pour constituer les planètes.
