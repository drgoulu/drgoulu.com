Les étiquettes anti-vol contiennent une puce [RFID](w:Radio-identification) qui émet un code en passant dans le portique. En passant à la caisse, le code des articles payés est mémorisé, ou plutôt enlevé de la liste des codes valides. En passant dans le portique, si le code est toujours celui d’un article valide, l’alarme sonne.

Sur les vêtements, deux plaques de plastique contenant le RFID sont assemblées par un clou traversant le vêtement. A la caisse on enlève le clou avec un puissant aimant qui écarte les pièces maintenant le clou.
