*Réponse publiée [sur Quora](https://fr.quora.com/Quel-est-votre-sentiment-sur-les-mauvais-nombres/answer/Dr-Goulu)*

Les nombres mauvais ( [Evil number - Wikipedia](w:en:Evil_number) ) sont ceux qui ont un nombre pair de 1 dans leur représentation binaire: ( [A001969 - OEIS](https://oeis.org/A001969) )

0, 3, 5, 6, 9, 10, 12, 15, 17, 18, 20, 23, 24, 27, 29, 30, 33, 34, 36, 39, 40, 43, 45, 46, 48, 51, 53, 54, 57, 58, 60, 63, 65, 66, 68, 71, 72, 75, 77, 78, 80, 83, 85, 86, 89, 90, 92, 95, 96, 99, 101, 102, 105, 106, 108, 111, 113, 114, 116, 119, 120, 123, 125, 126, 129 etc

Je n'ai absolument aucun sentiment sur eux.
