*Réponse publiée [sur Quora](https://fr.quora.com/Quel-serait-le-meilleur-moyen-pour-commencer-dans-le-monde-professionnel-du-d%C3%A9veloppement-web/answer/Dr-Goulu)*

Trouver un employeur ou un client.

La différence entre l'amateur et le professionnel, c'est le pognon, pas la technique.

Vous pouvez faire toutes les formations, tous les tutos, tous les projets gratuits que vous voulez, vous serez toujours un amateur.

Pour être professionnel, vous pouvez être excellent, bon, moyen ou mauvais, la seule chose qui compte est de trouver quelqu'un qui vous paie pour travailler.
