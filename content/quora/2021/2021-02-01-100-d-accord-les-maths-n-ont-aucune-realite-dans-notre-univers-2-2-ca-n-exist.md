*Réponse publiée [sur Quora](https://fr.quora.com/Pouvez-vous-expliquer-la-dimension-4D/answer/Dr-Goulu)*

100% d'accord. Les maths n'ont aucune réalité dans notre univers. 2+2 ça n'existe pas. Deux cailloux plus deux cailloux, oui. Deux atomes plus deux atomes oui. Deux galaxies plus deux galaxies oui. 2+2 est une abstraction de "maths pures" permettant de décrire de manière générale l'addition de deux machins avec deux n'importe quoi.

Pour les dimensions c'est kif-kif : l'espace-temps d'Albert, Hermann et d'autres est juste une description abstraite qui permet de décrire avec précision ce qui se passe dans l'univers physique.

Si vous en avez une meilleure, le Comité Nobel sera ravi de l'examiner.
