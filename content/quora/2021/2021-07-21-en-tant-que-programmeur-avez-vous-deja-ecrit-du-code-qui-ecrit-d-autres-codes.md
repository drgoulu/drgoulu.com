Une macro Excel en VB (beark !) qui génère du code Delphi calculant toutes les formules d'une feuille Excel dans l'ordre de dépendances, en nommant et déclarant les variables par le nom des cellules…

On avait défini un cycle machine assez compliqué en Excel avec l'ingénieur mécanicien (positions, vitesses et accélérations de plusieurs éléments, en fait j'aurais du faire ça en matlab, ou plutôt octave pour des raisons de coût), mais après le run macro + copier /coller du code dans le soft de commande temps réel s'est révélé indispensable.
