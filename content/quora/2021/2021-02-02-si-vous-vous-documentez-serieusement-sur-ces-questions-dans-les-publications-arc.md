*Réponse publiée [sur Quora](https://fr.quora.com/Peut-on-prouver-que-des-civilisations-extraterrestres-ont-existé-et-disparu/answer/Serge-Garneau)*

Si vous vous documentez sérieusement sur ces questions dans les publications archéologiques, vous aurez toutes les réponses, elles sont (à peu près) connues.

Vous pouvez lire le roman historique "j'ai construit la grande pyramide" de Christian Jacq, très bien documenté.

Vous pouvez aussi les poser une à une sur Quora.

Ce n'est pas parce que vous ne connaissez pas les réponses qu'il n'y en a pas.
