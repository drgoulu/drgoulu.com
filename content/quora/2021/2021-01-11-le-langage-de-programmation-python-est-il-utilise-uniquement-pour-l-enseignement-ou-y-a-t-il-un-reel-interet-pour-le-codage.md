intéressant de poser cette question sur Quora, qui est écrit en Python :-)

[Why did Quora choose Python for its development?](https://medium.com/@paragyte2/why-did-quora-choose-python-for-its-development-fb9f6a63d7a2)

YouTube, Instagram, DropBox, Reddit et d'autres très gros sites sont (partiellement) écrits en Python

Et une ribambelle d'[Applications](w:en:List_of_Python_software), y compris des jeux 3D très connus sont (partiellement) écrits en Python.

(partiellement) signifie que dans un bon logiciel moderne, on utilise du code natif compilé (C/C++) pour les 20% de code qui tournent 80% du temps, et un ou plusieurs langages interprétés pour les 80% du code moins gourmand, mais qu'il faut modifier et maintenir en permanence. Et Python est l'idéal pour ça.
