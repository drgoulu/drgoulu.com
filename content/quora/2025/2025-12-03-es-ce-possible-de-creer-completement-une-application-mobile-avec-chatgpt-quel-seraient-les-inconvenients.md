*Réponse publiée [sur Quora](https://fr.quora.com/Es-ce-possible-de-cr%C3%A9er-compl%C3%A8tement-une-application-mobile-avec-chatGpt-quel-seraient-les-inconv%C3%A9nients/answer/Dr-Goulu)*

Chat GPT n'est pas terrible en programmation. Actuellement Claude 4.5 et Gemini 3 sont beaucoup plus impressionnants. Ils sont disponibles dans Antigravity, un clone de VSCode développé par Google que j'utilise pas mal ces temps-ci.

L'efficacité de ces outils dépend beaucoup de vos propres compétences en développement de logiciel.

Si vous n'y connaissez rien, le [Vibe coding](w:)peut marcher pour des programmes simples, surtout s'ils existent déjà. "fais un jeu de pacman pour smartphone Android"' devrait marcher.

Pour des projets complexes, vous devez quand même jouer le rôle de l' architecte logiciel, et l'agent IA génèrera du code du niveau d'un développeur junior. Vous devez avoir les idées claires pour lui faire écrire des modules les uns après les autres, créer des tests, intégrer, documenter etc sinon vous vous retrouvez rapidement avec du code spaghetti illisible truffé de bugs.

Mais franchement, si vous savez comment créer votre app avec des développeurs humains, vous y arriverez avec une IA. Hélas…
