*Réponse publiée [sur Quora](https://fr.quora.com/Quelle-est-la-diff%C3%A9rence-entre-un-bon-code-et-un-excellent-code/answer/Dr-Goulu)*

J’ai eu la chance d’assister à une conférence de [Niklaus Wirth](w:) où il a répondu à la question “quel est selon vous le meilleur langage de programmation ?” en disant “le meilleur langage de programmation sera celui dans lequel vous aurez du plaisir à lire le code de vos collègues.”

Je dois dire que c’est un plaisir que je n’ai pas souvent (sans vouloir critiquer mes collègues, d’ailleurs ils peuvent en dire autant de mon code…)

Dans cet esprit, je dirais qu’un bon code est lisible par vos collègues (pour qu’ils puissent y corriger les bugs que vous avez laissés…), alors qu’en lisant un excellent code vous vous dites “wow… ça m'étonnerait qu’il y ait encore des bugs ici”
