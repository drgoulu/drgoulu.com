Si vous pouvez remplacer votre boucle par une fonction mathématique, c'est que vous n'auriez pas du écrire la boucle.

Par exemple

```
somme=0
for i=1 to n do
  somme =somme+i

```

Calcule la somme des n premiers entiers

```
somme=n*(n+1)/2

```
